# 05 Tasks（仅未来增量定义）

本文件不创建、分派或执行实现任务。每项只有在 Board 批准完整 SDD 后才可转化为独立任务；任何规格变化先修订并重批。

## `T-01` ASR/模型基准与许可证锁定

- 输入：`A-01/A-05/A-07`、固定中文公开/合成许可语料、目标 Mac 矩阵、候选 manifests。
- 输出：可复现实验报告、设备/OS/模型 hash、CER、partial/final 延迟、RTF、峰值内存、磁盘体积、许可证/SBOM；推荐单一 adapter/config。
- 验收证据：原始聚合指标（不含私人录音）、重复运行命令/配置、许可证文件 hash、门槛 Board 决议。
- 停止条件：需真实用户录音、许可证不清、需网络 ASR、持续成本或所有候选不达门槛；停止并升级 Board。

## `T-02` Session/SQLite 与迁移

- 输入：`C-01…C-05, A-02`。
- 输出：事务 schema/repository、幂等事件与版本迁移。
- 验收证据：契约测试、迁移/回滚夹具、乱序/重复/跨 session 拒绝证据。
- 停止条件：需要更改 required 字段/语义或 SQLite 不再为真相源；回到规格重批。

## `T-03` 麦克风权限与捕获状态

- 输入：`P-01,D-01…D-03,A-06`。
- 输出：仅麦克风 TCC 流、状态机、单路 frame 输出。
- 验收证据：fresh/allowed/denied/restricted 截图与结构化事件；静态证明无 Screen Recording 请求路径。
- 停止条件：需要系统音频/ScreenCaptureKit、目录例外或绕过用户授权；停止升级。

## `T-04` 音频原子落盘与恢复

- 输入：`C-01/C-02/C-04/C-05,D-04/D-11/D-12,A-03/A-04`。
- 输出：CAF writer、原子 commit、恢复/删除流程。
- 验收证据：故障注入覆盖磁盘满、rename/DB commit 崩溃窗口、重启恢复、hash/时长可读。
- 停止条件：可能覆盖/读取应用资产根外文件，或无法保证 ASR 与 writer 隔离。

## `T-05` ASR adapter 与滚动字幕

- 输入：`T-01` 已批准结果、`C-03/C-06,D-05/D-10`。
- 输出：有界 fan-out、partial 修正、finalized commit、ASR failure degradation。
- 验收证据：事件回放证明 revision/顺序/幂等；模型失败时录音持续且音频 commit。
- 停止条件：候选 engine/config 未获批准、契约需破坏性变化、依赖云。

## `T-06` 列表、重开与时间点播放

- 输入：`P-04,D-01/D-06/D-07,C-01…C-03`。
- 输出：本地 Session 列表/详情、finalized 字幕点击 seek、播放状态。
- 验收证据：重启后重开；固定音频标记测量误差满足 `M-08` 批准阈值。
- 停止条件：需 Markdown/云/完整会议记录或无法由单调时间定位。

## `T-07` 端到端失败矩阵与隐私审计

- 输入：`M-01…M-08`、全部已批准增量。
- 输出：最小端到端验收包与隐私/日志扫描报告。
- 验收证据：每个 M 场景的命令、夹具、截图/日志/DB 查询/hash，证明无网络和无敏感日志。
- 停止条件：需豁免质量门、使用真实用户录音、外发产物或发现上传/权限越界；停止并升级。

依赖顺序：T-01 与 T-02 可独立；T-03 → T-04；T-01+T-03+T-04 → T-05；T-02+T-04+T-05 → T-06 → T-07。只有未来 Board 批准后，才允许由有权限的负责人创建这些实现任务。
